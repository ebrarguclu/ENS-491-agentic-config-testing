# tests/

This folder is for everything about tests, both curl's own tests and the new tests we
will ask AI to write.

| Folder | What goes in it | Deliverable |
|---|---|---|
| [existing/](existing/) | Our notes on curl's own tests: which tests use which options. The tests themselves stay in `systems/curl/tests/` | Stage 2 |
| [generated/](generated/) | New tests written by AI for option combinations that curl's tests do not cover, one subfolder per AI tool (for example `generated/claude-code/`) | D7 |
